A Chapa

Uma chapa nascida do
diálogo com a categoria.

A chapa União para Transformar reúne cinco profissionais com trajetórias sólidas na engenharia, na agronomia, nas geociências e na gestão pública do Amazonas. Nosso compromisso: um Conselho forte, moderno e presente.

Cada proposta foi construída em conformidade com o Regimento Interno do CREA-AM e calibrada pela realidade dos profissionais do interior e da capital. Não são ideias soltas — são metas concretas, com prazos e indicadores.

CREA-AM mais forte e moderno.

CREA Mais Digital

CAT em 24 horas

"Seu tempo vale. Sua carreira não pode esperar."

Fluxo 100% digital e automatizado para emissão da Certidão de Acervo Técnico em até 24 horas, com triagem por IA e aplicativo CREA-AM integrado.

CREA Mais Eficiente

Enxugar a máquina pública

"Menos desperdício, mais entrega para quem trabalha."

Diagnóstico administrativo completo nos primeiros 90 dias. Revisão de contratos, digitalização integral e eliminação de redundâncias operacionais.

CREA Mais Presente

Duas novas inspetorias por ano

"Onde houver um profissional, o Crea precisa estar presente."

Seis novas inspetorias no interior ao longo dos 3 anos de mandato, ampliando a capilaridade do CREA-AM em um estado continental.

Fiscais de Nível Superior

"Quem fiscaliza deve ter o mesmo nível de quem é fiscalizado."

Fortalecimento do quadro com fiscais de nível superior, garantindo credibilidade às autuações e valorização do profissional habilitado.

Inspetorias modelo contêiner

Reformas das três casas + coworking

Programa destaque

Rio, Campo e Floresta

"Antes de fiscalizar, o Crea-AM precisa estar presente."

Programa de regularização técnica do Setor Primário do Amazonas — agropecuária, engenharia florestal e pesca/aquicultura. Uma abordagem inédita: apresentar, educar, capacitar, e só depois fiscalizar.

01
Apresentar
CREA vai ao encontro do setor primário. Presença física nos rios, feiras e comunidades.
02
Educar
Cartilhas setoriais. O que é ART, quem precisa emitir, por que ela protege.
03
Capacitar
Profissionais aptos ao novo receituário agronômico, protocolos florestais e de pesca.
04
Fiscalizar
Orientada, progressiva. Penalidade é o último recurso, não o ponto de partida.

Configuração do Supabase

Para sincronizar os dados entre dispositivos e salvar permanentemente na nuvem, configure o Supabase.
supabase.com → Crie um projeto grátis → Copie a URL e a chave abaixo.

SQL para criar as tabelas no Supabase:

CREATE TABLE instagram_posts (
  id uuid DEFAULT gen_random_uuid() PRIMARY KEY,
  code text NOT NULL UNIQUE,
  tipo text DEFAULT 'p',
  url_original text,
  criado_em timestamptz DEFAULT now()
);

ALTER TABLE instagram_posts ENABLE ROW LEVEL SECURITY;
CREATE POLICY "leitura_publica_ig" ON instagram_posts FOR SELECT USING (true);
CREATE POLICY "escrita_autenticada_ig" ON instagram_posts FOR INSERT TO authenticated WITH CHECK (true);
CREATE POLICY "delete_autenticado_ig" ON instagram_posts FOR DELETE TO authenticated USING (true);

CREATE TABLE galeria (
  id uuid DEFAULT gen_random_uuid() PRIMARY KEY,
  titulo text NOT NULL,
  data_evento text,
  imagem_url text NOT NULL,
  criado_em timestamptz DEFAULT now()
);

CREATE TABLE eventos (
  id uuid DEFAULT gen_random_uuid() PRIMARY KEY,
  titulo text NOT NULL,
  dia text, mes text, hora text, local text,
  status text DEFAULT 'breve',
  criado_em timestamptz DEFAULT now()
);

-- 2. Ativar Row Level Security
ALTER TABLE galeria ENABLE ROW LEVEL SECURITY;
ALTER TABLE eventos ENABLE ROW LEVEL SECURITY;

-- 3. Qualquer visitante pode LER
CREATE POLICY "leitura_publica_galeria"
  ON galeria FOR SELECT USING (true);

CREATE POLICY "leitura_publica_eventos"
  ON eventos FOR SELECT USING (true);

-- 4. Só admin autenticado pode ESCREVER/DELETAR
CREATE POLICY "escrita_autenticada_galeria"
  ON galeria FOR INSERT
  TO authenticated WITH CHECK (true);

CREATE POLICY "delete_autenticado_galeria"
  ON galeria FOR DELETE
  TO authenticated USING (true);

CREATE POLICY "escrita_autenticada_eventos"
  ON eventos FOR INSERT
  TO authenticated WITH CHECK (true);

CREATE POLICY "delete_autenticado_eventos"
  ON eventos FOR DELETE
  TO authenticated USING (true);

Após criar as tabelas, vá em Authentication → Users → Add user e crie o usuário admin com e-mail e senha.
